# The Big Board — branding (locked 2026-10-26)

- **Name:** The Big Board
- **Tagline:** Your empire, on one board.
- **Short description (Workshop search snippet):** Business command panel
  for Big Ambitions: track buildings, businesses, staff, factory, sales
  and stock in one phone app, sitting alongside the vanilla apps.
- **Version policy:** public releases start at **0.9.x = beta**. The beta
  label is deliberate: invites bug reports, lowers the cost of early bugs,
  makes supporting (donations) feel natural. **1.0.0** only when stable
  and community-approved.
- **Handles (reserve at release):** Discord server "The Big Board",
  GitHub repo `the-big-board`.
- **In-game identity:** phone button title "The Big Board" , panel header "THE BIG BOARD", teal "B" tile icon, `Player.log` tag
  `[Mod:0000000000 The Big Board]`.
- **Never:** paid features, "Pro" split, renaming again without a very
  good reason.
